## 介绍
**autoBGI** 是一个以 Go 为后端、Vue 为前端的 BGI(Genshin Impact) 自动化管理与日志分析工具。它整合了自动执行任务、背包统计、OBS 录屏/回放控制、AI 对话支持与飞书/TG 机器人通知等多种功能，目标是为 BGI 用户提供一体化的自动化运维与日志可视化工具。

界面基于 **Vue**，后端使用 **Go** 实现。

---

## 软件架构
- **后端**：Go 语言（go1.23.2）
- **前端**：Vue + Node.js（node 22.13.1）
- **构建脚本**：`build.bat`

## 安装教程

### 1. 下载程序
访问 [Gitee Releases](https://gitee.com/wangjian0327/auto-bgi/releases)，

下载最新版本的 **auto-bgi** 本体和最新版的exe文件。

下载完成后，解压即可本地，将 **auto-bgi.exe**文件放进目录。

---

### 2. 启动服务
解压完成后，直接双击运行程序，默认端口为 **8082**。  
在浏览器访问：  

```
http://<IP地址>:8082
```

📌 **注意**：  
- IP 地址可以在程序黑窗口中看到，如下图所示：

![显示 IP 地址](./assets/image-20250809102055339.png)

复制该 IP 地址并在浏览器打开。

也可以在托盘打开



---

### 3. 初始配置

先登录，账号和密码在根目录下，abgiUser.yaml，可以自行修改。

默认账号密码是：abgi

登录标题，默认隔壁老王，可以自行更改

![image-20251206095440599](./assets/image-20251206095440599.png)



打开网页后，向下滚动，找到 **autoBGI 配置**。

- **第一步**：配置 BGI 安装路径（到 `exe` 文件夹即可）
- **第二步**：点击保存并重启程序
- **第三步**：继续配置其他选项

![配置界面示例](./assets/391c3f25cda6d59bd9a70723abd1c6fe.png)

### ✅录屏功能


需要配合obs使用,下载地址：[OBS](https://obsproject.com/zh-cn)，

简易教程如下：

开启后会启动obs录屏功能,请确保obs已经安装并开启远程控制,

obs地址和密码填写正确，否则无法使用录屏功能。

请确保开起来websocket连接。

如果需要回放，请确保打开回放缓存功能。

abgi会根据关键字自动录制回放。

简单来说，开启回放缓存功能，开启websocket连接就行了

## 常见问题

### 1. 启动后打不开网页？
- 检查程序是否运行
- 确认防火墙放行端口（默认 8082）
- 更换端口，打开根目录下main.json文件，找到8082，改成你喜欢的，记得前面的   :  别删除了

---

### 2. 备份不成功？
- 确认路径是否正确
- 检查是否有权限访问目标文件夹

## 命令行
在程序目录下执行：

```bash
auto-bgi.exe OneLong
```
作用：**软件启动，直接启动bgi运行一条龙**

```bash
auto-bgi.exe updateJs
```

作用：**软件启动，直接启动bgi并且更新脚本**

```
auto-bgi.exe online
```

作用：启动abgi，直接上线，调试模式
