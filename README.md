## 介绍
**autoBGI** (简称ABGI)是一个对BGI(全称BetterGI) 进行自动化管理与日志分析工具。它整合了自动执行任务、背包统计、OBS 录屏/回放控制、AI 对话支持与飞书/TG 机器人通知等多种功能，目标是为 BGI 用户提供一体化的自动化运维与日志可视化工具。

界面基于 **Vue**，后端使用 **Go** 实现。

---

## 软件架构
- **后端**：Go 语言（go1.23.2）
- **前端**：Vue + Node.js（node 22.13.1）
- **构建脚本**：`build.bat`

## 功能说明
### 🔍实时监测

✅ **查看桌面**

查看运行着ABGI的电脑桌面

✅ **发送截图**

配置了企业微信通知或者其他软件通知，即可将运行着ABGI的电脑桌面发给企业微信或者其他通知软件

目前可以进行通知的软件有，企业微信，TG，飞书，OneBot

有这些通知软件的，需在【提瓦特指挥所】-【ABGI】-【消息通知】进行填写相关内容

![实时检测-发送截图](./assets/实时检测-发送截图.png)

✅ **实时日志**

实时显示BGI运行时的持续输出的日志，支持多用户

✅ **ABGI日志查询**

对ABGI的日志进行了可视化

### 📊 数据分析

✅**查看狗粮日志**

该功能是与BGI中【AAA狗粮批发】JS脚本搭配使用的，对狗粮收益进行了可视化

如果你有联机的，联机收益会自动会自动相加，支持转换为统计图

✅**屑荧进村**

统计bgi交换或拾取数量超过10的材料，有相似度计算，只要不是ocr太离谱，程序都可以判断出材料真实名字是什么

✅**归档查询**

可以在ABGI的【配置组运行情况】里面，将每一个配置组进行归档，或者一条龙结束的时候，自动将今日所有的配置组运行情况进行归档，下次执行这个配置组就可以看见预计结束时间。配置组执行时间少于30s的，不进行自动归档，如果需要可以手动归档

✅**旅行者札记**

搭配BGI的JS脚本有【吃药统计】【背包材料统计】，摩拉收益需要你BGI的日志分析里填写了米游社的Cookie

可查看超过 **8000** 的材料

支持一键加入黑名单，一键删除黑名单

✅**配置组运行情况**

对BGI运行的配置组进行可视化分析，也可以点击查看详情，进行更加细致的分析

✅**采集管理**

搭配BGI的JS脚本【采集cd管理】使用，支持多用户，对采集数据进行记录，查看各采集材料的CD时间

### 🚀 自动化控制

简单来说，开启回放缓存功能，开启websocket连接就行了

## 常见问题

### 1. 启动后打不开网页？
- 检查程序是否运行

- 确认防火墙放行端口（默认 8082）

- 更换端口，打开根目录下main.json文件，找到8082，改成你喜欢的，记得前面的   :  别删除了
