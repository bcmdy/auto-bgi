## 介绍
**autoBGI** 是一款针对 **BGI 的自动化管理与日志分析工具**，集成了以下核心功能：
- 一条龙定时执行
- 背包统计、日志分析
- 自动备份、脚本管理
- 多种通知方式（企业微信 / TG）
- 米游社签到
- 实时日志查看

界面基于 **Vue**，后端使用 **Go** 实现，支持多用户访问。

---

## 软件架构
- **后端**：Go 语言（go1.23.2）
- **前端**：Vue + Node.js（node 22.13.1）
- **构建脚本**：`build.bat`

## 安装教程

### 1. 下载程序
访问 [Gitee Releases](https://gitee.com/wangjian0327/auto-bgi/releases)，

下载最新版本的 **auto-bgi** 本体和最新版的exe文件。

下载完成后，解压即可本地，将exe文件放进目录。

---

### 2. 启动服务
解压完成后，直接双击运行程序，默认端口为 **8082**。  
在浏览器访问：  
```
http://<IP地址>:8082
```

📌 **注意**：  
- IP 地址可以在程序黑窗口中看到，如下图所示：

![显示 IP 地址](./assets/image-20250809102055339.png)

复制该 IP 地址并在浏览器打开。

---

### 3. 初始配置
打开网页后，向下滚动，找到 **autoBGI 配置**。

- **第一步**：配置 BGI 安装路径（到 `exe` 文件夹即可）
- **第二步**：点击保存并重启程序
- **第三步**：继续配置其他选项

![配置界面示例](./assets/391c3f25cda6d59bd9a70723abd1c6fe.png)

## 配置说明

### main.json 配置说明

配置文件路径：`auto-bgi/main.json`

以下是各字段说明：

| 配置项                  | 说明                                                                 |
|-------------------------|----------------------------------------------------------------------|
| **OneLong**            | 一条龙定时配置                                                     |
| ├─ isStartTimeLong     | `true` 开启 / `false` 关闭                                         |
| ├─ OneLongHour         | 启动小时（0-23）                                                  |
| ├─ OneLongMinute       | 启动分钟（1-59）                                                  |
| **BetterGIAddress**    | BGI 安装路径（到 `exe` 文件夹）                                    |
| **content**            | BGI 关闭时发送的通知信息                                           |
| **ConfigNames**        | 一条龙配置单，七个对应七天，从周一开始                            |
| **BagStatistics**      | 背包统计脚本，需要关注的材料，逗号分隔                             |
| **post**               | 默认 `8082`，可自定义端口                                          |

## 功能说明
### ✅ 一条龙启动
- 支持指定配置单，并根据命名规则自动控制执行时间
- 一条龙启动之前，可以选择是否更新脚本
- 一条龙启动是否同时开启obs回放缓存

### ✅ 实时日志
- 网页实时显示 BGI 日志，支持多用户

### ✅ 背包统计
- 基于 **吉吉猫** 和 **摩拉 OCR** 脚本和**原石统计脚本**脚本
- 可查看超过 **8000** 的材料
- 支持一键加入黑名单，一键删除黑名单

### ✅ **收获超过10的材料**

统计bgi交换或拾取数量超过10的材料，有相似度计算，只要不是ocr太离谱，程序都可以判断出材料真实名字是什么

### ✅ 自动备份
- 默认备份 `User` 文件夹，每三天自动执行

### ✅ 调度器

  可以直接启动配置组（45.2版本以上），多个启动

### ✅ 脚本更新
- 订阅过的脚本，都会在这里显示，支持单个更新，批量更新，一条龙开始更新。

### ✅仓库提交记录（三天）

支持查看 `md` 和 `txt` 详情

### ✅归档记录

可以在配置组运行情况里面，将每一个配置组进行归档，或者一条龙结束的时候，自动将今日所有的配置组运行情况进行归档，下次执行这个配置组就可以看见预计结束时间。配置组执行时间少于30s的，不进行自动归档，如果需要可以手动归档

### ✅ 米游社签到

![image-20250901133817494](./assets/image-20250901133817494.png)

- 需获取 **stoken-cookie**，教程：[点击查看](https://hut.ao/zh/advanced/get-stoken-cookie-from-the-third-party.html)
- 只需要填如图两个值就行

### ✅地图追踪更新功能（茶包版本的不行）

功能说明：

选择配置组，选择地图追踪文件夹。

更新：

配置组有的会清理掉相关的地图追踪，再加入新的指定全部地图追踪进去，排到后面；

配置组没有的，直接加入进去。不点保存也可以，下次进来重新选择

### ✅录屏功能


需要配合obs使用,下载地址：[OBS](https://obsproject.com/zh-cn)，

简易教程如下：

开启后会启动obs录屏功能,请确保obs已经安装并开启远程控制,

obs地址和密码填写正确，否则无法使用录屏功能。

请确保开起来websocket连接。

如果需要回放，请确保打开回放缓存功能。

abgi会根据关键字自动录制回放。

简单来说，开启回放缓存功能，开启websocket连接就行了

### ✅狗粮联机功能

联机功能：上线，模板图片生成，专属匹配房间，公共匹配房间.

如果是今天跑的狗粮是A线，则选择什么模式上线就是什么模式

如果是B线，强制调机 

### ✅CD管理自动采集

配合CD管理自动采集脚本使用

## 常见问题

### 1. 启动后打不开网页？
- 检查程序是否运行
- 确认防火墙放行端口（默认 8082）
- 更换端口，打开根目录下main.json文件，找到8082，改成你喜欢的

---

### 2. 备份不成功？
- 确认路径是否正确
- 检查是否有权限访问目标文件夹

###

## 命令行
在程序目录下执行：

```bash
auto-bgi.exe OneLong
```
作用：**软件启动，直接启动bgi运行一条龙**

```bash
auto-bgi.exe updateJs
```

作用：**软件启动，直接启动bgi并且更新脚本**

```
auto-bgi.exe online
```

作用：启动abgi，直接上线，调试模式
